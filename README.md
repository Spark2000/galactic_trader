### Terminal-Befehle

Programm starten:
``uv run galactic-trader`` oder 
``uv run python -m galactic_trader``

Tests starten:
``uv run pytest`` oder
``uv run pytest --no-cov``(ohne Converage)

Mypy starten:
``uv run mypy``

Ruff Check:
``uv run ruff check .``

Interrogate Check:
``uv run interrogate -vv``
